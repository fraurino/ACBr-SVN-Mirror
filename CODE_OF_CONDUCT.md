# Código de Conduta

Este repositório existe para facilitar o acesso ao código do Projeto ACBr e promover colaboração técnica respeitosa.

## Compromissos

Esperamos comunicação cordial, críticas técnicas construtivas, respeito a diferentes níveis de experiência e cuidado com informações sensíveis.

Não são aceitos assédio, discriminação, ameaças, ataques pessoais, divulgação de dados privados ou envio deliberado de conteúdo malicioso.

## Aplicação

Os mantenedores podem moderar comentários, encerrar Issues ou restringir a participação quando necessário, de forma proporcional à conduta observada.

Para problemas de segurança, siga [SECURITY.md](SECURITY.md). Para questões relativas aos componentes originais, consulte o [Fórum ACBr](https://www.projetoacbr.com.br/forum/).

Este código se aplica aos espaços de colaboração deste espelho, não substituindo as regras dos canais oficiais do ACBr.
